# Current handoff

The Linux adapter uses numbered WAL segments, an absolute durable commit marker and strict v2 checkpoint manifests over immutable v3 runs. The public `DiskTable` API supports sequential writes, explicit rotation, snapshots, compaction, checkpoints, reopen and opt-in collection of obsolete run generations. [Active storage protocol](architecture.md#sequential-storage)

Under the documented I/O contracts, the predecessor strict v2 trace proves repeated locked recovery for the whole-file model. Its typed checkpoint contracts remain shared with the segmented adapter. An interrupted checkpoint preserves the acknowledged WAL. An uncertain write may add its one submitted frame. The checkpoint proofs share typed contracts for durable ordered run files and the exact restored table. The v2 proof no longer creates a synthetic v1 manifest to reuse the loader and run-set guarantees. Live lock and descriptor lifetimes and primitive effect reports still need to be connected to the complete native trace. [Verification status](verification-status.md) · [Disk proof obligations](proof-roadmap.md#disk-guarantees-to-prove)

The native segmented open route validates the strict checkpoint, selects marker-covered bytes and repairs the last required segment. From a complete lock-held inventory, exact read reports and healthy repair effects, Lean derives that the final retry returns the same table, generation, byte count and segment and leaves them durable. The next proof step composes segmented bootstrap, append, rotation, checkpoint, and repeated reopen in one trace with native lifecycle and effect reports. [Effectful retry proof](../lean/Alvoki/Storage/Disk/WalSegmentRetryReadEffects.lean) · [Remaining recovery and collection work](proof-roadmap.md#garbage-collection-contract)

The shared segmented writer routes append, staged marker, grouped file sync, rename and directory sync. Reported cuts select the previously acknowledged WAL suffix or that suffix with the submitted frame. The rotation handoff proves that the first append in the durable empty successor also retains the exact sealed prefix at every admitted cut. [Rotation-to-append proof](../lean/Alvoki/Storage/Disk/WalSegmentRotationCommit.lean) The aligned reopen proof settles the directory before syncing the keeper. The native process-death fixture exercises both the initial and rotated segments on both sides of marker rename. The lock model also derives the last-reference transition from a complete observation of one file description's retained slots and drop events.
