## Optimized reader and search

`lean/OptProofs.lean` proves that the tail-recursive machine-index search agrees with the original natural-number lower bound after index conversion. It derives the same partition guarantee for monotone logical keys. `wordMachine_eq` proves the optimized reader is equal to the original byte reader when the eight-byte extent is in bounds and the array size fits in a machine word. Each proof-carrying byte load and indexed store uses an explicit bound, and Lean checks the progress of the machine-index loops.

The parser acceptance proof certifies input bytes, header count and version, layout, and strict order at logical offsets. Checked record access agrees with those offsets, and the optimized lower bound partitions the keys of accepted blocks. The v1 run API checks natural-number indices before converting them to machine width. Scalar kernel access checks the record bound and returns zero at exhaustion. For every strictly ordered array within the format and machine bounds, `encodeV1` followed by `parseRun` and `Run.decodeV1` recovers the exact array. Decoding and re-encoding an accepted block reproduces its bytes. The baseline, scalar and indexed encoders are equivalent to `encodeV1`. The materializing decoders and the streaming checksum refine the same decoded rows. ## Checks and trusted boundaries

Run `bash scripts/check.sh` and `bash scripts/check-sequential.sh` locally. These are the stock CI commands. The Lean checks re-run the bundled kernel checker and apply an axiom policy allowing only `propext`, `Classical.choice`, and `Quot.sound`. The sequential check runs a negative axiom control, packed-table differential traces, and native fault and process-death fixtures. [Workflow](../.github/workflows/correctness.yml) · [Packed checks](../scripts/check.sh) · [Sequential checks](../scripts/check-sequential.sh)

Native execution relies on the compiler and runtime. The disk proofs use the stated Linux primitive effect contract, including filesystem persistence and handle lifetimes. The fixtures exercise process-visible outcomes. Power-loss claims range over the crash choices admitted by the model.
